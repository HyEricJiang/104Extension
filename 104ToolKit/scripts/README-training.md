# 準備模型訓練資料

同仁仍只交付一份「AI訓練資料_姓名.pdf」。管理者收到後，使用本工具將標註與原始履歷分離；不需同仁再交清單。

此工具只準備資料，不會連線、上傳或啟動任何模型訓練。`dataset.jsonl` 是中立格式，實際訓練服務仍需依其規格轉換。

## 執行

需要 Python 3.10 以上。在此資料夾執行：

```sh
python3 -m pip install -r requirements-training.txt
python3 prepare-training-data.py "/你的訓練PDF資料夾" --output "/新的拆分資料夾"
```

也可將第一個參數指定為單一 PDF。輸出資料夾必須尚未存在，避免覆蓋。

每份有效資料會輸出：

- `input.pdf`：移除全部標註頁與答案中繼資料，只保留原始履歷。
- `input.txt`：原始履歷可擷取文字，正規化相容字形。
- `expected.json`：人工標籤與完整原因，作為預期答案。

根目錄另產生 `dataset.jsonl`，每行為 `{"input":{"resume_text":"履歷正文"},"expected":{"label":"人工標籤","reason":"原因"}}`；以及 `errors.json`，列出未處理成功的檔案。

## 使用觀念

履歷是題目，標籤與原因是解答。訓練時，程式將 `input` 配對 `expected` 來學習；評估時，只給模型 `input`，再由程式拿模型輸出與 `expected` 比較。不要把整份含標註的 PDF 當作待判斷履歷上傳，否則模型可直接讀到答案。

工具依 PDF 內的頁數標記精確分離，支援多頁原因，不假設永遠只有一頁標註。請保留擴充套件原始輸出，不要重新列印或改寫中繼資料；舊版沒有標記的 PDF 會拒絕處理，應重新匯出。無可擷取履歷文字時會提示先做 OCR，不產生空白輸入。

正式使用前需抽查輸入中沒有標註，以及答案與該人才相符。相同人才應放在同一個訓練／驗證分組，避免同一履歷同時出現在兩邊。
