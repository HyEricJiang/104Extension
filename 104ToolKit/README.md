# 104 招募工作台 v1.5.1

雙分頁工作台：「下標籤」保存履歷的模型訓練分類；「複製與匯出」管理職缺群組、複製聯絡資料、匯出邀約履歷與 AI 訓練 PDF。

## 五個訓練分類

- 系統推薦但不合適
- 人工審核但需要推薦
- 人工審核但應該排除
- 不應排除需人工審核
- 不應排除應推薦

「移除標籤」會清除此履歷的本機標記並恢復為尚未標記；沒有標記時停用按鈕。之後的 PDF 匯出只產生一般邀約版。職缺群組、其他履歷及已匯出的 CSV／PDF 不受影響。

點選分類只寫入擴充功能本機儲存，不會分組或移動分頁；匯出時依標記另外產生訓練版 PDF。每份履歷使用搜尋識別碼或企業／快照識別碼作為鍵值；關閉分頁或重新開啟工具後仍可讀取。同份履歷的搜尋頁與搜尋預覽頁共用標記。不同來源的搜尋識別碼與快照識別碼不會自行合併，避免誤認為同一個人。

沒有識別碼時停用分類，請開啟完整的單份履歷。應徵頁會沿用 PDF 模組的履歷連結解析。標記只保留最新選擇與更新時間，不保存履歷全文、姓名或聯絡資料。標記保存在目前 Chrome 設定檔，不跨電腦同步；移除擴充功能會失去本機紀錄。

## 職缺群組與 PDF 命名

提供九個群組：Jr.Net PG、Sr.Net PG、Jr.Java PG、Sr.Java PG、Jr.QA、Sr.QA、SA、PM、不合適。

「不合適」同樣可加入群組並下載 PDF，供模型訓練使用。一般履歷檔名為「不合適_姓名.pdf」；訓練分類仍需依實際判斷選擇，不會因群組名稱自動指定分類。

選擇職缺再按「加入群組」，只移動目前網頁。同一視窗已有同名群組時直接加入並保留外觀，否則建立灰色群組。成功後記住上次選擇。一般履歷優先使用職缺群組作為 PDF 檔名前綴；無群組時才套用原有前綴設定。訓練版另外儲存，不會覆蓋一般版。複製或匯出執行中禁止職缺分組，以免影響批次範圍。

## 複製與匯出

整合工作流在複製前先確認資料夾授權，複製階段顯示 1/2、PDF 階段顯示 2/2；只有整個流程成功才顯示 OK，部分 PDF 失敗會顯示 ERR 與已完成份數。

保留 PDF 前後綴、等待時間、純複製、純匯出及安全停止。「開始複製並匯出」仍先整理聯絡資料，再回到起始分頁匯出 PDF。

每份履歷開始處理時先讀取目前的訓練標籤。取得姓名與 PDF 後，依狀態儲存：

| 履歷狀態 | 一般邀約版 | AI 訓練版 |
| --- | --- | --- |
| 有五分類中的任一標籤 | `Jr.Java PG_王小明.pdf` | `AI訓練資料_系統推薦但不合適_王小明.pdf`（以實際標籤替換） |
| 無標籤或已移除標籤 | `Jr.Java PG_王小明.pdf` | 不產生 |

一般版優先依來源分頁的 Chrome 群組命名，保留檔名後綴；沒有群組時沿用前綴模式與手動前綴。訓練版固定使用 `AI訓練資料_標籤_姓名.pdf`，不加入職缺或一般後綴。兩版使用同一次取得的 PDF 內容，不會重新開啟或重印履歷。同名檔案仍會加序號，保留原檔。

不再產生 CSV，也移除「重新下載分類清單」功能。同仁只需提供以「AI訓練資料_」開頭的 PDF。此命名只表示目前人工選擇的五分類，不自行判定 AI 是否出錯。更新不改名、不刪除以前已下載的 PDF／CSV，也不改動已保存標籤。

一般版先存入，再儲存訓練版；訓練版失敗時保留一般版、顯示失敗並列出兩版成功份數。處理中停止會完成當前人才的兩版，後續人才不再處理。沒有取得姓名或 PDF 時不產生任一版本。

## 選擇存放資料夾

在「複製與匯出」按「選擇資料夾」，於設定頁再次點擊按鈕，透過 Chrome 原生視窗選取目的地，再按「完成並返回原分頁」。工具頁會保留在背景，匯出期間請勿關閉。一般履歷與 AI 訓練資料共用此資料夾，不必輸入路徑。瀏覽器只提供資料夾名稱，工作台顯示該名稱，無法顯示完整磁碟路徑。

選取的資料夾控制代碼保存在擴充功能的 IndexedDB，之後重新開啟仍可讀取。每次開始匯出會先開啟或重用工具頁確認授權；許可仍有效時自動返回履歷開始作業，暫時許可失效時按「授權並繼續匯出」即可授權原資料夾，不必重選路徑。控制代碼遺失時才需重新選取，不會改存到其他地方。直接寫入的檔案不會出現在 Chrome 下載清單；遇到同名檔案會加上序號。每次批次開始時固定目的地，過程中改選只影響後續批次。

未選取資料夾前沿用既有下載設定；舊的子資料夾設定會保留但不再提供輸入欄。設定頁可切換「使用瀏覽器預設下載位置」，同時清除舊子資料夾設定。

## 安裝與更新

1. 完整解壓 v1.5.1 套件。
2. 在 `chrome://extensions` 重新載入已指向更新資料夾的「104 招募工作台」，或用「載入未封裝項目」選擇解壓後的 `104ToolKit`。
3. 停用獨立的舊 `104-resume-tab-classifier`，避免舊工具仍改動群組。
4. 不自動轉換舊的三種 Chrome 分類群組：新五分類不與舊分類一一對應，請依履歷重新標記。舊群組不會被刪除。

## 權限與維護

沿用現有 tabs、tabGroups、scripting、downloads、debugger、storage、activeTab、clipboardWrite 權限；履歷讀取限於 `https://vip.104.com.tw/*`，不傳送至外部服務。

- `output-directory.js`／`directory.html`／`directory.js`：資料夾選取、權限檢查、目的地保存與檔案寫入。
- `training-labels.js`：五分類設定、識別與標記保存。
- `classifier.js`：專用連線、訓練標記操作與職缺群組管理。
- `collector.js`／`collector-content.js`：聯絡資料收集。
- `pdf-exporter.js`：依狀態匯出一般與 AI 訓練兩版 PDF。
- `workflow.js`：先複製再匯出。

驗證：`node --test tests/*.test.cjs`。本機與模擬介面檢查不取代登入後的 104 實測。手動驗收應確認：標記五分類不移動分頁、重開工具仍讀得到、加入職缺群組不改標記、PDF 保留職稱命名、有標籤產生兩版、無標籤只產生一般版，並測試部分失敗與停止。

資料夾驗收：選取實際磁碟資料夾、重開工作台、匯出邀約履歷與 AI 訓練 PDF、檢查同名序號、取消選取保留設定，以及暫時授權失效後按「授權並繼續匯出」的流程。自動化 FileSystem／IndexedDB 檢查使用瀏覽器測試資料夾，原生選取視窗與登入後 104 匯出仍需手動驗證。

Chrome 的一次性資料夾許可可能隨最後一個同來源頁面關閉而撤銷；工具頁在返回履歷時保留，以維持匯出期間的許可。若 Chrome 顯示持續存取選項，可依使用需求選擇。
