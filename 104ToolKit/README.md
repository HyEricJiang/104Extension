## 操作模式

- **PDF 設定先行**：先設定檔名前後綴、下載資料夾及等待時間，後續工作流與單獨匯出共用同一組設定。
- **常用工作流**：從目前分頁往右，先複製聯絡資料，再回到起始分頁批次匯出 PDF。
- **純複製資料**：預設收合；點擊後可只複製本頁，或從本頁往右收集，再次點擊即可收回。
- **純匯出 PDF**：預設收合；點擊後可只匯出本頁，或從本頁往右批次匯出，再次點擊即可收回。
- **安全停止**：在目前資料或 PDF 處理完成後停止，避免留下半成品。

資料收集完成即代表成功。若 Chrome 因背景分頁失去焦點而拒絕其中一次剪貼簿寫入，介面不會再把它誤報為資料收集失敗。

## 安裝

1. 開啟 Chrome，前往 `chrome://extensions/`。
2. 開啟右上角「開發人員模式」。
3. 點選「載入未封裝項目」。
4. 選擇本資料夾 `104ToolKit`。
5. 建議先停用舊的兩個擴充套件，避免同時操作同一批分頁。

## 權限說明

- `tabs`、`tabGroups`：辨識目前分頁及向右的連續履歷分頁。
- `scripting`：讀取 104 頁面中的聯絡資料與履歷狀態。
- `downloads`：下載產生的 PDF。
- `debugger`：使用 Chrome 列印能力產生 PDF；執行時 Chrome 會顯示除錯提示。
- `storage`：保存 PDF 命名設定與執行進度。
- `clipboardWrite`：將 TSV 聯絡資料寫入剪貼簿。

所有頁面存取限制在 `https://vip.104.com.tw/*`，不會將履歷或個資傳送至外部服務。

## 維護結構

- `collector.js` / `collector-content.js`：聯絡資料收集模組。
- `pdf-exporter.js`：PDF 匯出模組。
- `workflow.js`：依序協調兩個模組，不包含資料擷取或 PDF 細節。
- `popup.html` / `popup.css` / `popup.js`：工作台 UI 與狀態呈現。

## 手動驗證

1. 在單一 104 履歷頁測試「複製本頁」。
2. 開啟三個連續履歷分頁，測試「本頁往右收集」並貼到 Google Sheet。
3. 測試「匯出本頁」並確認檔名與下載資料夾。
4. 測試「本頁往右匯出」及安全停止。
5. 測試「開始複製並匯出」，確認先完成剪貼簿資料，再產生所有 PDF。
6. 測試目前分頁右側接著非 104 頁面時，批次範圍符合預期。
