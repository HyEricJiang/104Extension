# 104 招募工作台 v1.4.0

雙分頁工作台：「下標籤」保存履歷的模型訓練分類；「複製與匯出」管理職缺群組、複製聯絡資料、匯出 PDF 與 CSV。

## 五個訓練分類

- 系統推薦但不合適
- 人工審核但需要推薦
- 人工審核但應該排除
- 不應排除需人工審核
- 不應排除應推薦

「移除標籤」會清除此履歷的本機標記並恢復為尚未標記；沒有標記時停用按鈕。之後的 PDF 匯出列為「未分類」。職缺群組、其他履歷及已匯出的 CSV／PDF 不受影響。

點選分類只寫入擴充功能本機儲存，不會分組、移動分頁或更改 PDF 檔名。每份履歷使用搜尋識別碼或企業／快照識別碼作為鍵值；關閉分頁或重新開啟工具後仍可讀取。同份履歷的搜尋頁與搜尋預覽頁共用標記。不同來源的搜尋識別碼與快照識別碼不會自行合併，避免誤認為同一個人。

沒有識別碼時停用分類，請開啟完整的單份履歷。應徵頁會沿用 PDF 模組的履歷連結解析。標記只保留最新選擇與更新時間，不保存履歷全文、姓名或聯絡資料。標記保存在目前 Chrome 設定檔，不跨電腦同步；移除擴充功能會失去本機紀錄。

## 職缺群組與 PDF 命名

提供九個群組：Jr.Net PG、Sr.Net PG、Jr.Java PG、Sr.Java PG、Jr.QA、Sr.QA、SA、PM、不合適。

「不合適」同樣可加入群組並下載 PDF，供模型訓練使用。群組前綴模式下檔名為「不合適_姓名.pdf」；訓練分類仍需依實際判斷選擇，不會因群組名稱自動指定分類。

選擇職缺再按「加入群組」，只移動目前網頁。同一視窗已有同名群組時直接加入並保留外觀，否則建立灰色群組。成功後記住上次選擇。職缺群組仍可作為 PDF 檔名前綴；訓練標記不會覆蓋它。複製或匯出執行中禁止職缺分組，以免影響批次範圍。

## 複製與匯出

保留 PDF 前後綴、等待時間、純複製、純匯出及安全停止。「開始複製並匯出」仍先整理聯絡資料，再回到起始分頁匯出 PDF。

每次 PDF 匯出後，另外儲存一份 `training-labels_時間.csv`，放在同一資料夾。包含：

- `pdfFilename`：PDF 檔名，包含重名自動加上的序號。
- `pdfPath`：直接儲存時為資料夾名稱／檔名（非完整磁碟路徑）；預設下載時採 Chrome 下載記錄，無法讀取時保留請求位置。
- `filenameVerified`：是否已完成直接寫入並確認名稱，或由 Chrome 下載記錄確認名稱；false 表示名稱待確認。
- `jobTitle`：來源分頁的群組名稱。
- `trainingLabel`：本次處理履歷開始時讀取的標記，未標記時為「未分類」。
- `resumeKey`、`labelUpdatedAt`、`exportedAt`：對應識別碼與時間。

只列入成功完成下載的 PDF。失敗或停止後尚未處理的履歷不列入。CSV 使用 UTF-8 BOM、標準引號轉義與試算表公式防護。直接儲存會等待寫入完成；使用瀏覽器預設下載時，CSV 提交下載不代表檔案已寫入完成，請確認下載狀態。

CSV 下載失敗不會刪除已完成的 PDF；可按「重新下載分類清單」匯出最近一次紀錄。分類清單會包含識別碼、檔名與本機路徑，請視為履歷資料的一部分保存，不上傳至公開 GitHub。

## 選擇存放資料夾

在「複製與匯出」按「選擇資料夾」，於設定頁再次點擊按鈕，透過 Chrome 原生視窗選取目的地，再按「完成並返回原分頁」。PDF 與分類 CSV 共用此資料夾，不必輸入路徑。瀏覽器只提供資料夾名稱，工作台顯示該名稱，無法顯示完整磁碟路徑。

選取的資料夾控制代碼保存在擴充功能的 IndexedDB，之後重新開啟仍可讀取。存取許可失效時會提示重新選取，不會改存到其他地方。直接寫入的檔案不會出現在 Chrome 下載清單；遇到同名檔案會加上序號。每次批次開始時固定目的地，過程中改選只影響後續批次。「重新下載分類清單」使用目前選定的資料夾。

未選取資料夾前沿用既有下載設定；舊的子資料夾設定會保留但不再提供輸入欄。設定頁可切換「使用瀏覽器預設下載位置」，同時清除舊子資料夾設定。

## 安裝與更新

1. 完整解壓 v1.4.0 套件。
2. 在 `chrome://extensions` 重新載入已指向更新資料夾的「104 招募工作台」，或用「載入未封裝項目」選擇解壓後的 `104ToolKit`。
3. 停用獨立的舊 `104-resume-tab-classifier`，避免舊工具仍改動群組。
4. 不自動轉換舊的三種 Chrome 分類群組：新五分類不與舊分類一一對應，請依履歷重新標記。舊群組不會被刪除。

## 權限與維護

沿用現有 tabs、tabGroups、scripting、downloads、debugger、storage、activeTab、clipboardWrite 權限；履歷讀取限於 `https://vip.104.com.tw/*`，不傳送至外部服務。

- `output-directory.js`／`directory.html`／`directory.js`：資料夾選取、權限檢查、目的地保存與檔案寫入。
- `training-labels.js`：五分類設定、識別、標記保存、CSV 與最近一次清單。
- `classifier.js`：專用連線、訓練標記操作與職缺群組管理。
- `collector.js`／`collector-content.js`：聯絡資料收集。
- `pdf-exporter.js`：PDF 與成功下載清單對應。
- `workflow.js`：先複製再匯出。

驗證：`node --test tests/*.test.cjs`。本機與模擬介面檢查不取代登入後的 104 實測。手動驗收應確認：標記五分類不移動分頁、重開工具仍讀得到、加入職缺群組不改標記、PDF 保留職稱命名、CSV 與成功 PDF 一一對應，並測試部分失敗與停止。

資料夾驗收：選取實際磁碟資料夾、重開工作台、匯出 PDF 與 CSV、檢查同名序號、取消選取保留設定，以及許可失效後的重新選取流程。自動化 FileSystem／IndexedDB 檢查使用瀏覽器測試資料夾，原生選取視窗與登入後 104 匯出仍需手動驗證。
