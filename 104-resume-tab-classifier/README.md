# 104 履歷分頁分類器

這是一個不蒐集資料的 Chrome 擴充功能。它只會在指定的 104 VIP 履歷搜尋頁顯示三個分類按鈕，並將目前分頁加入同名的 Chrome 分頁群組。

## 功能

- 推薦但不合適
- 人工審核但合適
- 排除但推薦
- 目前視窗沒有同名群組時自動建立。
- 已有同名群組時直接加入。
- 不保存、不匯出，也不傳送任何履歷資料。

## 安裝方式

1. 在 Chrome 網址列開啟 `chrome://extensions/`。
2. 開啟右上角的「開發人員模式」。
3. 按下「載入未封裝項目」。
4. 選擇本資料夾：`104-resume-tab-classifier`。
5. 重新整理已經開啟的 104 履歷搜尋頁。

## 使用方式

1. 將每份要分類的履歷開在獨立分頁。
2. 在頁面右側找到「履歷分頁分類」浮動面板。
3. 按下其中一個分類按鈕。
4. 目前分頁會移入同名群組；同名群組只會在目前 Chrome 視窗內共用。

## 權限說明

- `tabGroups`：用來查詢、建立、命名及調整 Chrome 分頁群組。
- 頁面存取範圍只限：`https://vip.104.com.tw/search/SearchResumeMaster*`。

本工具沒有使用 `storage`、`downloads` 或外部網路 API。

## 驗證清單

1. 在目標頁面確認浮動面板出現，其他網站不會出現。
2. 第一次按下任一分類，確認建立同名群組並加入目前分頁。
3. 另開一個目標頁面分頁後按相同分類，確認加入既有群組。
4. 改按另一個分類，確認目前分頁移到另一個群組。
5. 快速連點按鈕，確認不會建立重複同名群組。
6. 使用 Tab 鍵確認三個按鈕可依畫面順序操作，且焦點外框清楚可見。

## 疑難排解

- 看不到面板：請確認網址符合指定頁面，並在安裝或更新擴充功能後重新整理頁面。
- 顯示「擴充功能內容已失效」：通常是擴充功能剛重新載入，重新整理 104 頁面即可。
- 同名群組沒有共用：Chrome 分頁群組隸屬於個別視窗，請確認分頁在同一個 Chrome 視窗內。
